 📌 Descripción del Proyecto

Este proyecto corresponde al Trabajo Práctico Grupal N°1 de la materia Front End del 2° Año de la Tec. Sup. en Des. de Software, a cargo del profesor Luciano Ariel Martínez.

El objetivo fue desarrollar un sitio web utilizando HTML, CSS y JavaScript, aplicando buenas prácticas de estructura, diseño responsivo e interactividad.

El sitio cuenta con una portada principal, páginas individuales para cada integrante del equipo, una sección de bitácora y funcionalidades dinámicas mediante JavaScript.

 ⚡ JavaScript

 🔹 En la portada (index.html)
Se implementó una función que muestra un mensaje al hacer clic en un botón, generando interacción con el usuario.

 🔹 En las páginas individuales
Cada integrante implementó una función JavaScript, como por ejemplo:
- Cambio de color de fondo
- Mostrar/ocultar contenido
- Interacciones con botones
