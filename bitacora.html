Bitácora del Proyecto

🧠 Decisiones de diseño

Como equipo decidimos utilizar una estética moderna y minimalista, con una paleta de colores en tonos grises y celestes, buscando una interfaz clara, ordenada y fácil de navegar. También optamos por utilizar tipografías de Google Fonts para mejorar la legibilidad.

⚙️ Organización del trabajo

El equipo se organizó dividiendo las tareas entre los integrantes. Se creó una estructura base del proyecto con HTML, CSS y JavaScript, y cada integrante desarrolló su página personal. Se utilizó Git y GitHub para el control de versiones y trabajo colaborativo.

🚧 Dificultades encontradas

Durante el desarrollo surgieron dificultades relacionadas con la organización del proyecto, la conexión entre archivos y la implementación de estilos responsivos. También hubo desafíos al trabajar con Git y la gestión de ramas.

✅ Soluciones aplicadas

Las dificultades se resolvieron mediante la práctica, la investigación y el uso de herramientas como documentación oficial y asistencia con inteligencia artificial. Se logró organizar correctamente la estructura del proyecto y mejorar la comunicación del equipo.

🔄 Cambios realizados

A lo largo del desarrollo se realizaron mejoras en el diseño, la navegación y la estructura del código. Se ajustaron estilos CSS para lograr una mejor experiencia visual y se incorporaron funciones en JavaScript para agregar interactividad.
